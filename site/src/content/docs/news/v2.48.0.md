BMC-UI 4.5.0; bmcd 2.42.2 and tpi 1.10.0 are unchanged.

<!-- more -->

Firmware **v2.48.0**, 1 November 2026 — the first image to carry [BMC-UI 4.5.0](/changelog/bmc-ui/). Every item below is the repository's own changelog entry, taken apart; the whole entry is a click away under each one.

Console, Flash Node and USB show the four nodes side by side, so choosing one
is a single click instead of opening a dropdown first. Nothing else changes.

## Changed

- **Choosing a node is one click (BMC-UI 4.5.0).** The three pages that asked which node to act on now share one control: a row of Node 1 to Node 4 you can click, or move through with the arrow keys.

    <details class="note">
    <summary>The whole entry</summary>

    The node you arrived with from another page (`?node=`) is still preselected, and what each page sends to the board is unchanged.

    </details>

- **Choosing a node is one click.** Console, Flash Node and USB picked one of four modules from a dropdown: open it, then choose. <small class="tp-tag">BMC-UI 4.5.0</small>

    <details class="note">
    <summary>The whole entry</summary>

    They now share a `NodePicker`, a horizontal radio group (`role="radiogroup"`, named by its visible label, one tab stop, arrows move and choose, Space and Enter choose) that fits four options on one row at a phone's width. The value, the `?node=` preselection and every API call are unchanged. A new gate, `npm run node-picker-test`, drives the demo build with real mouse and key events.

    </details>
