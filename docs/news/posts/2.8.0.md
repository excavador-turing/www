## bmcd 2.10.0

What the bmcd this image carries changed, from [its own changelog](../../changelog/bmcd.md).

**Changed**

- Rust 1.98.1 across the workspace, dependencies refreshed, and 23 clippy lints
  fixed rather than suppressed. `NodeType`, `DummyValidator` and
  `FalseValidator` deleted as unused; an `unreachable!()` in `utils` replaced by
  `as_chunks::<2>()`, which makes the case impossible instead of asserting it.

## BMC-UI 3.7.0

What the BMC-UI this image carries changed, from [its own changelog](../../changelog/bmc-ui.md).

**Added**

- Pick a version to install: the firmware page lists what every configured
  source offers, with how each compares to the running version and how much is
  known about its integrity, and sources are editable in place.

**Changed**

- Node 24, TypeScript 6, Vite 8, ESLint 10, and all twenty advisories cleared.
- The release is a tarball with `SHA256SUMS`; upstream's auto-release is inert.
